# RepScan Phase 1 — 爬虫引擎（手动 + Mock + API 模式）

## 当前环境诊断（2026-04-24）

| 渠道 | 状态 | 原因 |
|------|:----:|------|
| 微博 s.weibo.cn | ❌ | 需登录 + 反爬检测 |
| 知乎搜索 | ❌ | 需登录，JS渲染 |
| 小红书 | ❌ | 需 Cookie + Sign 签名 |
| Reddit API | ❌ | 被封 |
| 淘宝 | ❌ | 400 Bad Request |
| 百度 | ❌ | 验证页 |

**结论：** 当前互联网环境不允许无认证公开爬取中文社交平台。

## Phase 1 爬虫策略

### 1. 手动输入模式（核心 MVP）
用户直接在 Web UI 粘贴抱怨文本 + 选择来源平台 → 分析引擎处理。
优先级最高，不依赖任何外部 API。

### 2. Mock 数据生成器
内置测试数据生成器，产出自带标签的示例数据，用于测试分析引擎和 UI。

### 3. API Key 模式（Phase 2）
当用户提供 API Key 后：
- 微博: 使用微博开放平台 API
- 知乎: 使用知乎 API (需申请)
- Reddit: 使用 Reddit OAuth API
- Google/Bing: 使用搜索 API
